# v5–v7 三轮迭代小试

在两款模型上各做 D1 基线、D2 逐字重放、D6 选项换位。每份卷独立调用，共 50 题。每轮先检查两份 D1 的覆盖，再运行对照。跨轮保留题号、题序和 A/B 映射，只替换上一轮出现语义翻转、漏答或问号的题。将两端点各自三次相同且彼此相反的题记为稳定分歧。两端点各自稳定且选择相同的题计为稳定同选。结果是开发数据。

GPT 经 Chat Completions 调用，使用网关采样和推理默认值。Sonnet 经 Messages 调用，5 和 4.6 请求指定 `thinking.type=disabled`，5.5 指定 `between_tools`。输出上限分别为 Sol 4,096、Luna 2,048、Sonnet 8,192。网关实际生效的隐藏参数未知。模型 ID 由回复回显，底层权重与实际路由未独立核实。第三轮沿用 v4 的 Luna 和 Sonnet 5.5 配置，以便观察相同端点在新卷上的表现。

## 跨轮对照与费用

v4 和 v7 使用相同的 Luna/Sonnet 5.5 端点和显式请求配置，两版文字与语义均相同的题有 31 道。30 道在两轮中均为六份卷稳定同选，同时对应六次的语义选择逐项相同。其余一道 Q02 在 v7 出现翻转。v7 的 3 道稳定分歧都来自 v4 之后换过的题。v4 的 Q01 已替换，因此无法用 v7 对照验证原 Q01。v5 和 v6 同时更换题库及模型对，轮间数字不能单独归因于换题。
