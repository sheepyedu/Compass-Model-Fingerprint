# 中文价值取舍题的选题依据

本项目测量的是一个 API 端点在给定条件下如何权衡两个都可行的做法。候选题通过内容审阅后，区分度和鲁棒性由开发数据估计。AI Research Compass 只提供了研究起点。

## 证据与设计决策

| 证据和原文位置 | 支持的设计 | 适用范围 |
| --- | --- | --- |
| Chiu 等，DailyDilemmas，ICLR 2025，§2、图 1。用 1,360 个日常困境表示两个方案、相关各方及价值冲突。 [论文](https://openreview.net/pdf/c15ea9371589a6b1198247817e83269d14acce7a.pdf) | 为每题固定行动者、约束和两种行动，每个行动都有收益与机会成本，再写等义版本。 | 从现有日常困境结构取方法。题目内容按本项目的低风险范围独立编写。 |
| Scherrer 等，MoralChoice，NeurIPS 2023，§3.3、§4.2–4.3、图 3–5。低歧义题多有明确共识，高歧义题中既有较稳定偏好，也存在改写波动和高不确定性。 [论文](https://arxiv.org/abs/2307.14324) | 选有真实取舍的题，避免一个方案明显占优。尽量消除事实歧义，同时保留偏好上的两难。 | 英文逐题多次采样的结果。中文一次整卷仍需实测。 |
| Han 等，Value Portrait，ACL 2025，§2–3。由真实用户交互构造任务，用持有不同价值观的人能否作出不同回应检验题目的内容效度。 [论文](https://aclanthology.org/2025.acl-long.838/) · [项目与图示](https://holi-lab.github.io/ValuePortrait/) | 使用实际会遇到的建议问题。审阅时明确写出为何两种合理的人可能各选一边。 | 人类一致性用于验证题目能表达某种价值，端点之间是否可分需要另测。 |
| Song 等，Human Psychometric Questionnaires Mischaracterize LLM Behavior，EMNLP 2026，摘要和主要结果。比较八个开放权重模型的人格／价值自评与在日常任务中生成特定回答的概率。 [论文](https://aclanthology.org/2026.emnlp-main.1993/) | 用具体行动建议代替“你重视什么”或“你是什么性格”的量表自评。 | 研究比较的指标与本项目的逐题语义一致率不同。 |
| OECD，PISA 2012 Technical Report，问卷中的 Forced Choice 段落。Pew，Writing Survey Questions，Question wording 与 Response categories 小节。 [技术报告](https://www.oecd.org/content/dam/oecd/en/about/programmes/edu/pisa/publications/technical-report/PISA-2012-technical-report-final.pdf) · [写题指南](https://www.pewresearch.org/writing-survey-questions/) | 选项对称地陈述代价，题内只操纵一个主要取舍。固定题号、互换 A/B，允许无法判断时答问号。 | 原始方法面向人类问卷。它们帮助控制混杂，端点识别准确率需独立验证。 |
| Liu 等，中文道德选择，Findings EMNLP 2024，图 2、表 8。四个模型三轮完全同选率为 56%、98%、89%、89%，模型之间同选率约 58%–84%。 [论文](https://aclanthology.org/2024.findings-emnlp.272.pdf) | 同时衡量端点间选择差异和端点内稳定性。 | 中文邻近证据，场景、答法、采样以及每次提示的题量与本实验不同。 |
| Salecha 等，PNAS Nexus 2024，图 1–2；Röttger 等，ACL 2024，§4.3–4.5。题组长度和轻微提示改动都可能改变模型回答。 [题组效应](https://doi.org/10.1093/pnasnexus/pgae533) · [提示改写](https://aclanthology.org/2024.acl-long.816/) | 题面改写、顺序、提示角色分别控制。两种卷长需要实际分别发出。 | 原研究的分数变化量无法作为本项目验收阈值。 |

## 内容审阅

选用五类各十题。规划与灵活性比较预先排定和现场调整，探索与熟悉度比较新体验和可预测性，速度与完善度比较早交付和再打磨，统一规范与个性化比较互操作和局部适配，保留余量与充分利用比较应对变化和当下收益。每类使用多种日常场景，降低同一个主题反复出现造成的相关性。选项的固定语义只由数据映射记录，卷面不显示维度名称。

逐题检查以下条件：

1. 两个行动可同时满足给定的硬性约束，各自有一个容易说清的收益和代价。
2. 两边使用类似语气，不用“正常人”“负责”“显然更好”这类词给出暗示。
3. 不涉及政治、族群身份、医疗诊断、违法行为或安全关键决策。前文也不包含用户立场、身份扮演、威胁、奖励或暗示某个选项更好。
4. 四套题干逐项核对行动者、数量、时限和可行性。语义选项复用固定文字。审阅中修正了 Q13 的时段、Q25 的延后起点、Q37 的讲解时长和 Q47 的容量含义。
5. 题序和 A/B 方向独立记录。低覆盖整卷退出建档和选题。对实测接近全员同选的题，模型间概率差自然较小。若同一模型多次翻转，少数比例惩罚会降低排序。

一个例子是 Q24。指南已经能用，新成员陆续到达。现在发布文字版能让先到的人马上使用，先加示意图再发则更易跟做，但会增加等待。审阅能确定两边均成立。区分价值取舍、发布习惯及整体风险基调仍需要模型数据。

## 聊天提示干扰

D7 在固定系统指令末尾追加一段普通聊天封装说明，声明纯文本界面和无需工具。问卷正文、顺序、选项方向、接口、请求头和采样设置沿用 D1。比较 D1–D7 时同时看 D1–D2 的逐字重放差异。常规用户前文仍由 D1–D3 测，连续消息包装仍由 D3–D4 测。网关注入的隐藏系统提示无法直接观测。HTTP 请求头主要用于传输和协议，只有服务端确实把它映射到模型输入时，才构成模型提示。D7 测的是施加的系统提示差异，服务头和客户端产品环境留作后续独立对照。

D7 每端点额外一次，列为本轮探索性测试，结果不进入选题、建档或正式稳定性门槛。两套组合模板先生成并做摘要封存，正式盲测时再发。
