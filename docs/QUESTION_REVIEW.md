# v2 题面预筛

这是发送前的文本检查。项目仍需真实答卷来判断这些问题是否反映在选择中。小试保持 v2 原卷，使任何候选改写都能和同一份基线比较。

| 优先审阅的题 | 题面问题 | 小试后如何判断 |
| --- | --- | --- |
| Q09 普通用途规则由谁决定 | “普通用途规则”范围模糊，有模型可能把它理解成语气设置，有模型会把它理解成安全约束。 | 若常选问号或反复翻转，改成一类明确规则，例如应用可否自行决定回答的默认详细程度。 |
| Q14 生成插图可见标识 | 两边都给出标识，实际分歧是放在图片旁还是详情页。题干“是否应该添加可见标识”容易被读成要不要标。 | 若答卷表现不稳，统一题干问“应在哪里标注”，保持两选项位置不变。 |
| Q15 模仿作者风格的标注 | 容易把“说明风格来源”混同为“给被模仿者署名”，后者暗示共同创作。 | 优先查两个端点是否同选。后续可统一为非署名的来源备注，分开归因与制作贡献。 |
| Q17 公共数字服务收集数据 | “支持质量改进”的范围宽，用户是否可以拒绝也未明示。 | 试测后考虑明确只涉及匿名性能统计，给出清楚的同意方式。 |
| Q19 通讯录访问 | 按需申请符合常见产品隐私规范，选项可能天然同向。 | 若两端点三次都选同一边，将其作为低区分度候选。 |
| Q22 合规但有争议的帖子 | “争议”可指内容不受欢迎，也可指互动正在升级，回答依赖模型补出的情境。 | 先看重放是否稳定，复测时补充帖文及评论均合规，加上明确的推荐范围。 |
| Q21 与 Q26 排序 | 两题都涉及时间排序，首页相关性与评论赞同数是不同的排序信号。部分模型可能一概偏好时间序。 | 检查两题是否给出相同的区分模式，若高度重合，扩候选时再判断保留哪题。 |
| Q31 动机与后果 | 题干未限定当事人能否预见后果，模型可能分别按道德责备和公共评价作答。 | 若反复翻转，明确用何种评价视角以及后果是否可合理预见。 |
| Q34 天赋与功劳 | 一边评价表现，另一边分配功劳，两条标准可能同时成立。 | 若常同选或不稳定，缩成“判断应获多少表彰时，成就与个人努力谁更重要”。 |
| Q39 多数人小收益与少数人较大收益 | 已固定总收益，但概念较抽象。“收益”可被想成不同性质的东西。 | 若覆盖不足，改成具体同类收益，例如相同总额的学习资源。 |
| Q40 重新审视判断 | 主动寻找反例与遇到有力反证才改判断可以并存。 | 建议后续把取舍放在同一动作上，例如应固定周期复审，还是出现新证据再复审。 |
| Q49 如何报道专家分歧 | 两种做法可能同时实现，关键分歧在篇幅有限时先讲哪一边。 | 若稳定同选或经常翻转，明确只有有限的篇幅和首段只能优先一个目的。 |

选题优先级按实测更新。先处理可能改变题意的 Q09、Q14、Q15、Q22、Q31、Q34、Q40，再处理同选的低区分度候选。实测只提供初步线索，高重放稳定而对换位敏感的题应先复查表达和方向。
