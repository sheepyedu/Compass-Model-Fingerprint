# 下一步实验规划

本文件把批准方案 4 v3 展开为实施顺序和验收检查点。题库题材按后续用户要求扩展到科技、网络、哲学与低敏公共议题。真实采集仍需冻结可用端点。

## 1. 定义候选端点与调用账本

- 在首次模型作答前获得至少两个经授权可用的候选端点。若有同系列相邻版本，纳入比较。记录服务商、请求模型名、可见版本、接口路径、采集日期、统一系统指令、显式采样参数、已知默认值、计费单位、价格及价格出处。无法固定的别名报告为采集时段内的端点。密钥与身份映射分开存放，提交公开文档时仅保留可公开的配置。
- 按官方接口和网关说明核查包装及可用参数。区分连续两条 `user` 消息被保留、已知合并、被拒绝及行为未知。拒绝或合并时记录实际行为，不改发其他包装。
- 以冻结清单定义候选数 \(M\)。为每个端点持久化六个开发槽位和四个盲测槽位。清单冻结后，端点故障和不兼容均保留其席位与评估分母。
- 首次付费调用前，用实际消息长度（含系统提示及包装开销）、固定输出上限和端点价格预算。短卷尚未冻结时，用封存长卷或任一合规 30 题子集的最大长度作为短卷的保守上界。对账时分别记录单次短卷、单次长卷及总采集费用，费用未知项保留状态。发送前原子占位，关闭自动重试。超时、未知计费和发送后中断占原槽位，恢复时只发送未占用的槽位。

## 2. 版本化题库、封存模板并先跑合成验收

当前 v7 题库的五类各 10 题，覆盖 AI 开放与技术路线、数据与创作权利、网络平台治理、哲学原则及其他低敏公共议题。每题直接问更支持哪项规则或原则，固定题号与语义选项。核对四套中文题干是否保留相同对象、前提和取舍。避开党派表态、敏感个人身份、医疗、暴力和要求迎合某种观点的前文。

50 题卷均衡 A/B，每个语义方向各 25 次落在 A。D1–D6 共用系统指令和卷外示例 `Q00 A`，允许答 `?`。盲测模板 B1、B2 均预先封存完整 50 题的中性材料、独立措辞、题序及方向。B1 的前文与卷面放一条 `user` 消息，B2 放同一次请求的连续两条 `user` 消息。短卷冻结后按题号从各自长卷取 30 题，保留措辞、相对顺序和 A/B 映射。

采集前以合成输入检查命令行全流程，至少覆盖：

| 合成用例 | 预期结果 |
| --- | --- |
| 正常结束的无换行末行，截断、流中断或未知结束的无换行末行 | 前者可解析。后三种舍弃未终止末行，保留此前有换行的完整行。 |
| 全角、大小写、未知题号、说明行、缺项、单独 `?`、全卷拒答 | 归一化后只认符合整行协议的答案。已知题号后的解释、多选或缺答案是该题非法行，其余行按类别计数。 |
| 合法行与非法同行题号的两种顺序，重复相同答案，不同答案冲突 | 同一个本卷题号出现至少两次即整题无效。先处理末行，然后计数。 |
| 50 题分别有效 39/40，30 题分别有效 23/24 | 39 与 23 整卷剔除，只保留诊断；40 与 24 过线。低覆盖卷不建档、不选题、不评分，稳定性涉及该卷时共同有效为 0、覆盖为 0%、一致率不可计算。盲测仍计一次未命中。 |
| 两份可用长卷共同有效 39 题，或共同有效 40 题且同选 35 或 36 题 | 39 题覆盖不达标，35/40 不达标，36/40 恰好通过。 |
| 选项换位、长短卷对齐、两条消息合并、所有必测配对 | 能正确还原语义，出现合并时相关包装对照标为不可测，报告可列出全部七对。 |
| 最高分平票、身份字段隔离、失败盲测槽位 | 平票未识别，评分仅使用题号与语义选择，固定分母完整。 |
| 并发启动、占位后中止、失败与超时 | 同槽位只占一次，每端点最多十次发送尝试。 |

## 3. 用六次开发采集诊断稳定性与生成档案

同一开发配置在各端点交错执行。每次发起独立新会话，一次发送一卷，格式异常不补问。D1 同时用于格式核验。

| 配置 | 请求内容 | H1 的配对 |
| --- | --- | --- |
| D1 | 单条消息，基线 50 题 | 参照 |
| D2 | 逐字重放 D1，消息和参数相同 | D1–D2，重放 |
| D3 | 单条消息，固定中性前文加基线卷 | D1–D3，前文 |
| D4 | 同一请求的两条连续 `user` 消息，正文按预定分隔符拼接后与 D3 一致 | D3–D4，包装 |
| D5 | 单条消息，等义措辞，D1 的顺序和方向 | D1–D5，等义改写 |
| D6 | 单条消息，逐题交换 D1 的 A/B，其余相同 | D1–D6，位置 |

建档只用各模型共同可测且整卷过线的开发配置。对模型 \(m\) 和题目 \(i\)，语义选项一的次数为 \(a_{mi}\)，有效次数为 \(n_{mi}\)，估计 \(p_{mi}=(a_{mi}+1)/(n_{mi}+2)\)。题目得分是所有模型对之间概率的平均绝对差，减各模型内部少数选项比例的均值。无有效观测时概率和少数选项比例均按 \(0.5\) 处理。每个维度按得分取六题，优先每模型有效率均达 80% 的题，同分按题号排。缺位按最低模型有效率、得分、题号依次补足，报告补位题。无共同配置时记录建档失败，盲测分母保持预定值。

可用开发数据按配置整组留出，每折重选题、重建档，D1 与 D2 同折。比较 5、10、20、30、50 题及固定种子随机题基线，只用于解释题数效应。完成后锁定模型档案、30 题清单、消息和采样参数、解析器、评分器、阈值以及用于盲测排序的随机种子。

## 4. 每端点四次真实盲测，先锁定完整预测再揭盲

每套封存模板各发送一份真实 30 题、一份真实 50 题，共四次。固定种子随机安排长短卷发送顺序。采集器管理身份映射、HTTP/结束状态、可见版本、用量和原始回复。匿名评分输入只传每份卷的题号与语义选择。每份卷独立按语义选项累加对应的对数概率，缺题跳过，唯一最高分才给预测。锁定全部预定槽位的输出后才揭盲并计算剩余 H1 配对。盲测数据不回流建档。

- **H1 稳定性**。除五个开发配对，加入 D1–B1、D1–B2 的真实 50 题配对。在每对中设共同有效题数为 \(v\)，同选题数为 \(s\)。每端点七对必须都满足 \(v/50\geq 0.80\) 且 \(s/v\geq 0.90\)，按原始计数判断。逐对报告 \(s/v\)、\(v/50\)、翻转题号。包装合并、发送失败或答卷不可用导致的必测项标为不可测，整体不能判通过，另列已观察的未达标项。
- **H2 一次调用识别**。真实 30 题为主检验，每端点两份短卷的命中数为 \(h_m\)，宏平均为 \(\sum_{m=1}^{M}h_m/(2M)\)，需至少 90%。唯一且正确的预测计 1，所有超时、未发送、失效、低覆盖、平票、错误或建档失败均计 0。真实 50 题另用同样固定分母报告。
- 对 30 与 50 题按端点、模板配对，报告都对、仅短卷对、仅长卷对、都未命中，以及正确率差。给两种长度各自的混淆矩阵（含未识别）、每端点预测与命中数及失败原因、均匀猜测基线 \(1/M\)。宏平均达标而个别端点少于 2/2 时点名端点和混淆对象。仅报告固定模板的原始计数。

## 5. 发布实验报告与复现材料

报告首页并列 H1/H2 判定、关键不可测项、真实 30/50 题成绩、单次鉴别费用及采集总费用。仓库保留版本化题库、冻结清单和模板、工具、合成验收及复现说明。两项假设均通过时，可称一次 30 题调用在本轮实际端点和固定条件下获得初步支持。更短问卷、跨客户端、跨工具链或另一个 API 路径的效果由后续真实整卷调用检验。
