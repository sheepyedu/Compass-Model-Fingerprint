# v8–v10 三轮迭代小试

三轮各选两个端点。每个端点先发 D1，达到整卷门槛后再发 D2 原样重放和 D6 逐题换位。每次为独立会话的一份 50 题卷。逐轮只替换上一轮出现语义翻转、漏答或问号的题。未触发替换的题、题序与 A/B 映射保留。两端点各自在三份卷上同选且彼此选择相反，才计稳定分歧。

GPT 走 Chat Completions，采用网关采样与推理默认值，Terra 输出上限 1,024，Sol 输出上限 4,096。Claude 走 Messages，Sonnet 5 和 4.6 指定 `thinking.type=disabled`，5.5 指定 `between_tools`，输出上限 8,192。各端点内配置不变。模型 ID 以网关回显为准，底层权重、路由与隐藏参数未独立核验。
